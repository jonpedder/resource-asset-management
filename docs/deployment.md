# Deployment

1. Provision the hosted feature service from the finalized schema manifest.
2. Create the Web Map.
3. Create Workflow Manager groups, roles, diagram, extended properties, and template.
4. Register a new OAuth app and redirect URIs.
5. Generate `app-config.json` from the new item IDs.
6. Run unit tests and deployment verification.
7. Run disposable approved and denied end-to-end smoke tests.
8. Reconcile and require zero inconsistencies.
9. Enable GitHub Pages.
