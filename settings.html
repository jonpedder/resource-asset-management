About Resource & Asset Management

This authenticated application combines NIMS-typed resource inventory, facilities, ICS 213RR requests, and Workflow Manager tracking in one operational workspace.

System of record: ArcGIS feature services store resources, facilities, and requests. Workflow Manager is authoritative for each request's live step and audit trail.

Use the map workspace
  • Search and filter resources by status, category, kind, or type.
  • Select a resource in the inventory to inspect details and zoom the map.
  • KPIs summarize resources, facilities, availability, and requests.
  • Use the Requests control to inspect current request records.
Request an inventory asset
  1. Sign in and select an asset in Resource Inventory.
  2. Select Create ICS 213RR request.
  3. Review typing and quantity, then add incident, date needed, and Notes / justification.
  4. Submit the request. A successful request must be linked to a Workflow Manager job.
Process requests through the workflow

Open Request Approval and select a request. Actions remain disabled until its job link, correlation property, and live Workflow Manager step are verified.

  • Logistics: review, source, mobilize, return, and restock.
  • Approver: approve or deny with a required note.
  • Operations: deploy and demobilize.
  • Requestor: revise and resubmit a denied request.
Contact and reports

Contact Requestor opens an email containing the requested asset, complete request details, and the signed-in approver's signature. Export Request PDF opens a print-ready request; choose Save as PDF.

Configure the application

Settings are saved as local browser overrides. Branding, labels, theme and status colors affect all app pages. Connection overrides apply after Save & reload. Reset removes browser overrides and restores deployment defaults.

Troubleshooting

Sign-in does not complete

Verify the portal URL, OAuth client ID, and registered redirect URI.

Layers do not load

Confirm service URLs, layer indexes, sharing, and account privileges.

A workflow action is unavailable

Confirm the request is Linked, contains a WFMJobId, and is correlated to the live job GlobalID.

PDF does not open

Allow pop-ups for this site. PDF export uses the browser print dialog and does not depend on an external PDF library.
